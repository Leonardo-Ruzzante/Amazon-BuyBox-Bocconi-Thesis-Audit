# Amazon Buy Box Scraped Data

This folder contains the raw scraped CSV datasets collected from Amazon.it offer-list pages. These files are preserved as source data and are not edited in place.

## Files

| File | Product setting | Rows | Columns |
|---|---:|---:|---:|
| `Alimentari - Capsule caffè.csv` | Food and coffee capsules | 2,797 | 32 |
| `Illuminazione - Lampadine Philips.csv` | Philips light bulbs | 1,457 | 32 |
| `Sport e tempo libero - Smartwatch - Xiaomi Mi Smart Band 6.csv` | Xiaomi Mi Smart Band 6 smartwatch | 9,424 | 32 |
| `Ufficio - Agenda moleskine.csv` | Moleskine planner | 654 | 32 |

## Role in the thesis archive

The econometric analysis uses the Xiaomi Mi Smart Band 6 dataset as the main empirical input. The other CSV files document the broader scraping record and remain available for source-level inspection.

The same Xiaomi file is also stored under:

```text
../Amazon-BuyBox-Econometrics-Analysis/Datasets/Sport e tempo libero - Smartwatch - Xiaomi Mi Smart Band 6.csv
```

That copy is the repository-local input used by the econometric notebooks.
