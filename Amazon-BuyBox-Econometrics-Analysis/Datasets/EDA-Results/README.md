# EDA Results

This folder contains exploratory data-analysis and audit tables produced by the first part of the econometric notebook.

The files document the transformation from the raw scraped offer-level extraction to the analytical candidate samples. They include raw-type audits, delivery and shipping checks, seller-presence diagnostics, market-structure summaries, sample-construction tables, variable-provenance outputs, and balance summaries.

All files in this folder are CSV tables. They are derived outputs generated from the raw Xiaomi Mi Smart Band 6 CSV and the transformation logic inside the notebook.

These files validate data construction and sample restrictions. They are not independent raw data sources.
