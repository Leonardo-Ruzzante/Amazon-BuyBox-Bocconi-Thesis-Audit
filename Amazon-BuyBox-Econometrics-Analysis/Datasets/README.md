# Econometrics Datasets and Outputs

This folder contains the raw input used by the econometric analysis and the exported outputs produced by the notebooks.

## Contents

```text
Datasets/
├── Sport e tempo libero - Smartwatch - Xiaomi Mi Smart Band 6.csv
├── EDA-Results/
├── Econometrics-Results/
├── Figures/
└── Machine-Readable-Results-Aggregated/
```

## Raw econometric input

`Sport e tempo libero - Smartwatch - Xiaomi Mi Smart Band 6.csv` is the raw scraped dataset used in the econometric analysis. It contains 9,424 rows and 32 columns.

The broader scraped-data archive is stored in:

```text
../../Amazon-BuyBox-Scraped-Data/
```

The thesis econometric analysis is based on the Xiaomi Mi Smart Band 6 dataset.

## Derived outputs

`EDA-Results/` stores exploratory data-analysis outputs and audit tables.

`Econometrics-Results/` stores model outputs, robustness checks, inference diagnostics, synthesis tables, and aligned thesis-facing exports.

`Figures/` stores figure files in PNG and PDF formats.

`Machine-Readable-Results-Aggregated/` stores a compact JSONL representation of the tabular empirical record and an index file documenting reconstruction metadata.

## Preservation rule

The raw CSV is the immutable input for the econometric pipeline. Derived outputs are archived as part of the replication record and can be regenerated by running the notebooks.
